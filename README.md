# 🏗️ Construction Measurement Converter

## 📖 Description

Construction Measurement Converter is a simple web application that allows users to convert measurements between different units.

Users enter a measurement value, select the original unit, and choose the unit they want to convert to. The application calculates and displays the converted result.

This project was created to practice JavaScript, handling user input, and working with measurement conversions.

## ✨ Features

- Enter a measurement value.
- Select the original measurement unit.
- Choose the unit to convert to.
- Supports length, weight, volume, and temperature measurements.
- Display converted results.

## 🛠️ Tech Stack

- **HTML5** – Structures the webpage, input fields, dropdown menus, and buttons.
- **CSS3** – Styles the webpage, layout, and background image.
- **JavaScript** – Handles user input, measurement calculations, and displaying results.

## 🧠 What I Learned

- How to capture user input using JavaScript.
- How to work with dropdown menus and selected values.
- How to use JavaScript functions to perform calculations.
- How to use conditional statements to handle different conversions.
- How to dynamically update the DOM with calculated results.

## 🚀 How to Use

1. Visit the [Live Website](https://constructionapisimple.netlify.app/).
2. Enter a measurement value.
3. Select the unit you are converting from.
4. Select the unit you want to convert to.
5. Click the conversion button to display the result.

## 💻 How to Install

1. Clone the GitHub repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
   ```

2. Open the project folder in VS Code.
3. Open `index.html` in your browser or using Live Server.
